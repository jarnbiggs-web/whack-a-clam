# 🐚 เกมทุบหอยหรรษา (Whack-a-Clam) ✨

เกม 2D Mini Web Game สไตล์ตีตุ่น (Whack-a-Mole) ในธีมชายหาดพาสเทลแสนหวาน ออกแบบเป็นพิเศษสำหรับเด็กวัยประถม 3 เข้าใจง่าย กราฟิกน่ารัก ตัวอักษรชัดเจน และมีระบบเสียงเอฟเฟกต์/เพลงประกอบสังเคราะห์ในตัว ไม่ต้องต่อเน็ตก็เล่นได้ทันที!

---

### 🎮 วิธีเปิดเล่นเกม
1. ดับเบิลคลิกเปิดไฟล์ [index.html](file:///c:/Users/jarnb/Desktop/pro1/index.html) ผ่านเว็บบราวเซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari, Firefox)
2. กดปุ่มสีชมพู **"เริ่มเล่นเลยจ้า!"**
3. ใช้เมาส์คลิก หรือแตะนิ้วบนหน้าจอ (หากใช้แท็บเล็ต/มือถือ) เพื่อทุบน้องหอยที่โผล่ขึ้นมาจากหลุมทราย

---

### 🌸 กฎกติกาแสนง่าย (เวลา 30 วินาที)
| ตัวละคร | คะแนน | รายละเอียด |
| :--- | :---: | :--- |
| **หอยสีชมพูยิ้มหวาน** 🌸 | **+10 คะแนน** | โผล่มาบ่อย ทุบติดต่อกันจะสะสมคอมโบได้คะแนนพิเศษ! |
| **หอยไข่มุกทองคำ** 👑 | **+30 คะแนน** | หายาก มีประกายดาววิบวับ ทุบแล้วคะแนนพุ่งพรวด |
| **น้องปูก้ามโต** 🦀 | **-5 คะแนน** | ระวังน้องปูนะจ๊ะ อย่าไปทุบโดน ไม่งั้นจะโดนหนีบ! |

---

### 💖 ฟังก์ชันพิเศษสำหรับเด็ก ป.3
- **กราฟิกโทนสีพาสเทล & เวกเตอร์การ์ตูน SVG:** ลายเส้นคมชัด สีหวาน สดใส สบายตา ไม่กระตุก
- **เมาส์ค้อนของเล่นน่ารัก:** เมื่อเลื่อนเมาส์บนคอมพิวเตอร์ เคอร์เซอร์จะกลายเป็นค้อนของเล่นสีหวาน และมีท่าทุบเมื่อกดคลิก
- **ระบบเสียงสังเคราะห์ (Web Audio API):** มีเสียงตีตุ๊กตา "ปิ๊ง!", เสียงไข่มุกประกายวิบวับ, เสียงปักเป้า/ปู และเสียงดนตรีกล่องเพลงกล่อมน่ารัก สามารถเปิด/ปิดเสียงหรือดนตรีได้
- **สรุปผลพร้อมกำลังใจ:** สรุปคะแนน ตัวที่ทุบได้ พร้อมเหรียญรางวัลและข้อความชมเชยสร้างสรรค์
